# How-to-create-a-route-between-the-markers-in-the-Angular-maps

This sample demonstrates how to obtain the coordinates for markers and navigation routes from the Google Maps Directions API and integrate them into the Syncfusion Maps to plot the route between designated locations.

Add your key for the Google Maps Directions API to the **index.html** file located in the **src** folder.

## Project prerequisites
Make sure that you have the compatible versions of Visual Studio Code in your machine before starting to work on this project.
Ensure you have Node.js installed on your machine to run the project dependencies and scripts effectively.

# How to run this application?

To run this application, follow the steps below:

## 1. Clone the Repository
First, you need to clone the repository named `how-to-create-a-route-between-the-markers-in-the-Angular-maps` and navigate to its directory on your system.

Open the **Command Prompt** or **Terminal** and run the following commands:

```bash
git clone https://github.com/SyncfusionExamples/how-to-create-a-route-between-the-markers-in-the-Angular-maps project
cd project
```

## 2. Install Dependencies
Once the repository is cloned and you are inside the project folder, install all the necessary packages required to run the application locally.

Run the following command:

```bash
npm install
```

This command will install all the required **Angular** packages for the project.

## 3. Run the Application
Finally, you can now run the application using the Angular CLI command:

```bash
ng serve
```

This will start the development server and serve the application in your default browser.
